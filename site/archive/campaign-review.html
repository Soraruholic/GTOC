D33：Carroll 与 Meyer–Schuster 的路线证据

这是一轮原始资料核对与开发决策，独立化学专家审核仍 pending。专利叙述、某例测得收率、真实动力学参数和游戏教学进度是不同证据层，不能互相替代。

1. Carroll：C5 烯醇到 C8 酮有直接底物证据

US5874635A ↗ 的 Example 1 明确使用 2-methyl-3-buten-2-ol 与 methyl acetoacetate，在环状碳酸酯介质和铝催化体系中进行 Carroll 反应；文本也明确甲醇、CO₂ 的去向和蒸馏残液再用。这里的 2-methyl-2-hepten-6-one 与从另一端编号的 6-methylhept-5-en-2-one 是同一目标连接图，必须通过图身份核验，不能只匹配名称。

支持开发的净计量：C₅H₁₀O + C₅H₈O₃ → C₈H₁₄O + CH₄O + CO₂。分段教学应为乙酰乙酸酯交换 → 烯醇形式 / [3,3] 重排 → β-酮酸脱羧及互变异构。不能把全净式画成一次普通亲核加成，也不能遗漏 CO₂ 和甲醇。

该专利 Example 3 的溶剂是 γ-丁内酯，报告多批再用残液；这不能直接证明当前游戏母液能安全循环，更不能把其给出的平均收率写成无时间依赖的反应速率常数。下一个 C8 切片应保留未反应乙酰乙酸甲酯、催化剂、溶剂和高沸残余，并把收率 / 纯度 / 转化率分开记录。

2. 一个需要避免的误引：Saucy–Marbet 不等于 Carroll

CN108299171B ↗ 虽在背景中讨论 Carroll，但其发明路线使用 C5 烯醇与 2-烷氧基丙烯，采用 Saucy–Marbet 反应。它可作为备选工艺与背景对照，不能当作“乙酰乙酸甲酯 Carroll 工艺”的直接实现证据。

路线决策：优先保留已经冻结的 U03/U04 Carroll 分段路线。Saucy–Marbet 放入备选，不在同一个 reactionId 里混用原料、净计量或机理箭头。

3. Meyer–Schuster：有特定底物实例，但催化体系必须明确

CN113248357B ↗ 明确以脱氢芳樟醇制柠檬醛，采用 MoO₂(acac)₂ / Ph₃PO、特定有机酸及溶剂体系。Examples 1–4 使用 NMR 内标法报告不同催化剂用量下的目标产物收率分别为 53%、67%、70%、78%。这是专利作者的单例测定，不是独立复现实验，也不是统一纯化分离收率。

其分子式守恒 C₁₀H₁₆O → C₁₀H₁₆O，只能证明净同分异构关系；不能由此推断唯一微观路径、E/Z 产物分布、氧原子的同位素去向或活化能。酸介质中的 Rupe、脱水及其他副路径必须作为适用域问题审查，不能建立“任意酸 + 任意炔醇 → 任意醛”的万能模板。

JP4349676B2 ↗ 作为柠檬醛生产的第二份工艺候选资料存档。其参数不与上面的 Mo / Ph₃PO 体系混合。综述 Engel 与 Dudley, 2009 ↗ 此轮出版社全文入口返回浏览器检查页，没有把未读到的全文标为完成审核。

路线决策：U05 脱氢芳樟醇的库存切片可继续；U06 先做明确催化包的净端点与候选杂质池，并保留 geranial / neral 的独立身份。微观金属催化箭推在依据补齐和独立审阅前保持未开放，不能用酸催化通用漫画替代。

4. 本轮新机理的审核范围

  • U01：端炔去质子化、炔基羰基加成、后处理恢复 OH；强碱与水分阶段操作，氨与 NaOH 保留。图采用离子极限式，不是自由炔负离子的溶液物种分布。
  • U02：半加氢与继续还原的净端点，分别追踪一份 H₂；没有画未经验证的金属表面基元过程。C5 末端烯烃不具有 E/Z，不能添加一个虚假的顺反标签。
  • A01：氯乙酸羰基质子化 → 甲醇加成 → 介质质子接力 → 水离去 → 再生催化酸；7 状态完整原子映射。Cl 取代基保留，酯氧与水氧的教学映射不证明真实溶液中无氧交换。

全部状态采用统一几何筛查和二维动画；通过筛查说明没有达到项目阈值的粗大几何冲突，不证明完整反应路径不存在碰撞，更不代表优化中间体或 TS/IRC。
