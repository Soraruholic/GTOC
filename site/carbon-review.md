# D34–D38：Claisen、Carroll 与 C10 重排的证据边界

本页为开发者的来源核对与教学审阅包。独立化学专家尚未审阅，不把通过程序检查写成化学专家批准。[工场](carbon-lab.html) · [验收手册](carbon-manual.html)。

## 1. U03 的当量碱与盐

采用匹配甲酯的甲氧基：2 乙酸甲酯 + NaOMe → 乙酰乙酸甲酯产物钠盐 + 2 甲醇。课堂依次展开 α-H 转移、碳亲核加成、四面体中间体崩解和更酸性的 β-二羰基产物再次去质子化。最后一步使碱成为产物盐的组成，不能标成完全再生的催化剂。

酸化净式：产物钠盐 + HCl → 中性 MAA + NaCl。课堂水合质子承担实际的质子转移；游戏 HCl 为净酸当量。剩余 NaOMe 也被中和，生成额外甲醇与 NaCl。溶剂、浓度、酸水含量以及真实活度未展开；不把干态离子画法解释为溶液物种分布。

本批 2 mol 乙酸甲酯只按教学进度生成 0.9 mol MAA，残留 0.2 mol 酯；实际消耗的 1 mol NaOMe 最终全部进入盐账。该数值不来自工业转化率拟合。U03 是标准机理教学与软件计量切片，尚未核验一套 GTNH 原料体系下的工业 Claisen 操作规程。

## 2. U04 的直接工艺证据与三对电子

[US5874635A](https://patents.google.com/patent/US5874635A/en) 明确支持 2-methyl-3-buten-2-ol 与 methyl acetoacetate 制 methylheptenone 的 Carroll 工艺。说明书列举五元环碳酸酯 / 内酯及多种铝催化剂；软件选用碳酸乙烯酯与 Al(OiPr)₃ 作为已列举类别内的候选催化包。**这不是 Example 1 的逐项配方复现**，也没有把其工艺收率移植成当前模型参数。

课堂将其分为：酯交换净端点 → 形式烯醇 → 六原子 [3,3] 重排 → β-酮酸 → 脱羧 / 互变异构净端点。只在有明确六边图编辑的 [3,3] 帧画三支协同电子对箭头，每支从一条键出发、指向新形成或增强的键；不把“六处键阶变化”误画成六对电子。

三对电子对应的六处键阶变化经过程序逐边校验；原子与总电荷守恒，终点连接图匹配 C8 酮、CO₂ 与甲醇。原酯的两个氧在形式烯醇 / β-酮酸教学图中的去向是这一表示的映射，不能当作实验同位素追踪结果。酯交换、烯醇化及脱羧的催化微观过程没有补造箭头。

净式：C₅H₁₀O + C₅H₈O₃ → C₈H₁₄O + CH₄O + CO₂。0.80 反应进度和 0.95 C8 分配都是未标定教学参数；理想组分分配尚未替代成蒸馏或液液分离模型。未生成的未知高沸副产物没有被虚构为确定分子，当前只保留已知未反应物 / 溶剂 / 催化组分；因此不能声称工业杂质谱完备。

[CN108299171B](https://patents.google.com/patent/CN108299171B/en) 的实际主路线是 Saucy–Marbet，继续作为不同工艺的备选；不与当前 MAA 路线共用净计量或 reactionId。

## 3. U05 的 C10 骨架与后处理

C8 酮 + 乙炔 → 脱氢芳樟醇，两个乙炔碳均留在 C10 骨架。教学课堂复用端炔活化、羰基加成、分阶段水后处理的电子账；NaNH₂、NH₃、NaOH 分别入账。羟基新立体中心未指定，不虚构对映选择性。

本版先从真实 C8 库存取料，再使用第二份真实乙炔单元；强碱仍为明确夹具。0.90 净进度、0.98 分配不是动力学求解。残余 C8、乙炔和未分出的 C10 留在 9 号机，后处理盐和氨进入 11 号机。

## 4. U06 的催化条件与立体组成

[CN113248357B](https://patents.google.com/patent/CN113248357B/en) Examples 1–4 使用 MoO₂(acac)₂、Ph₃PO、4-叔丁基苯甲酸和甲苯，报告柠檬醛的 NMR 内标收率 53%、67%、70%、78%。这些是专利作者报告的特定条件结果，不能当作分离收率、普遍转化率或速率常数。

软件明确登记这一催化包，但固定投入量与 0.60 进度是教学场景；未复现专利反应器、加料、温度 / 压力或浓度。净端点动画从 C10 炔醇比较到 citral，**不声称已经解析 Mo 配位机理或真实氧同位素去向**。酸体系可能存在其他反应路径；当前不具有任意炔醇通用预测能力。

Geranial 是 2E 身份，neral 是 2Z 身份；RDKit 核验其指定构型并分别收录。游戏产出的 `citral` 仍为立体组成未定的组分账，不按一个猜测比例分成两者。身份比较课不等于 E/Z 转化轨迹。后续 U07/U08 对立体组成的要求必须单独定义，不能把未定池直接宣称成全反式原料。

## 5. 几何、教学与专家审阅项

新 6 课 / 20 状态使用同一键长和非键接触筛查；三维离散切换，不做逐原子线性穿越。构象局部力场处理不等于量子优化，键长筛查不等于路径无碰撞或能垒正确。三维与二维电子账使用同一原子映射。

建议专家优先检查：U03 共振极限式及产物脱质子步骤；Carroll 形式烯醇和六电子协同箭推；U05 新立体中心范围；U06 净端点和未定 E/Z 池；理想分配与实际杂质谱之间的差距。轨道、优化端点及 TS/IRC 保持独立研究任务，当前没有新增量化结果。
