## 2. 工程与守恒约定

新增 `CouplingProcess` 和 9 组分扩展，基础目录 37 条身份保持原值，合计 46 条。每条偶联线包含 8 个设备库存，液流、气体、吸附水分别记账。物质量用 BigDecimal，每次候选提交检查全元素、形式净电荷与容量。

新增工段复用 `UnitService` 的主线程验证 → 工作线程计算 → 主线程重核绑定 → 单写入器落盘 → 主线程确认，不引入第二个权威写入器。操作请求仅传窗口 / 会话 / 序号 / 库存版本 / 操作码；玩家身份来自真实连接。每个角色有操作白名单，容器验证原锚点、维度、距离、所有者和当前打开窗口。

旧世界保持 v2.1 直到首次创建偶联线，该事务一并升级到 v2.2。旧版本严格拒绝新 schema，避免无声抹去新增字段。回退需要恢复升级前完整世界备份和匹配 JAR。新版本继续支持旧乙酰化模型。

上限：16 条旧乙酰化线 + 8 条偶联线；共享 4096 条持久回执 / 4 MiB 权威文件；每条新线最多 128 条工序记录；每设备液流 32 mol、气体 4 mol；仅第 0 台存 0.5 mol 吸附水。到限拒绝写入，不会静默截断。

## 3. 模型限制必须保留

没有将计量工序伪装成动力学：GUI / 网页曲线横轴为工序序号。没有密度与有效体积时显示 mol，不生成虚构的浓度；没有反应热和 EOS 时保留 null。

水失活优先、OH 先于端炔是有限教学域规则。**过量 EtMgBr 对 C14 醛的竞争加成尚未模拟**；因此这个模型只能用于守恒、试剂当量和工序教学，不能预测真实选择性。95% 参数不吸收该缺失项作为“经过标定的收率”。

后处理净式中的 MgBr₂、MgSO₄ 是有效溶解组分，不代表唯一离子对、配合物或固体盐。此前规划中“Mg/Br/Cl 废物流”在这一硫酸工段修正为 Mg/Br/S。Cl 仍属于其他上游工序。

分离仅做声明的组分分配，留下目标物、底物、酸、水和溶剂损失；未解液液分配 / 蒸馏。三维仅做关键帧与坐标插值，未做中间体优化、TS 或 IRC。新的醇立体中心未指定，不能宣称全反式成品。

## 5. 供给与成本状态

本轮供给入口仍为开发夹具，尚未完成 GT 原生原料到 C14/C6 的生产链，也未授权把注册名相似的 `ether` 直接解释为已确认乙醚流体映射。原生审计、上游机器解锁与配方路径保留在专题研究中。

按干燥基线每收集 1 mol C20 炔二醇，投料比为：C6 与 C14 各 `1/0.931 = 1.0741 mol`，EtMgBr `2.2/0.931 = 2.3631 mol`，总乙醚 `10/0.931 = 10.7411 mol`，硫酸投料 `1.5/0.931 = 1.6112 mol`（实际消耗 `1.1/0.931 = 1.1815 mol`）。这些是本教学夹具的物料负担，不是货币、EU、电耗、工业生产成本或环境生命周期结果。

未计算：原生原料真实获取成本、设备制造/EU、加热/冷却/干燥/氢化公用工程、催化剂寿命、溶剂回收和连续多批清洗。当前不把这些未知项当成免费或零。
