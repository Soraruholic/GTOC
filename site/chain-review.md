# 串联后段化学审阅包

版本 0.4.0-va-chain-alpha1；独立化学专家审核待进行。没有向外部人员发送此文档。

## 1. 竞争加成修订

旧偶联 v1 保留；新建 v2 将 `min(nEtMgBr,nC14) × 0.25` 分配为 C16 镁醇盐，余下醛与 C6 双活化物按 95% 进度偶联。后处理得 C16H28O，C16 图已登记，镁盐流守恒。

这是顺序分配教学模型，不是相对反应速率解。优先专业问题：25% 分配与操作顺序的误导风险；是否用竞争速率或限定的当量变化案例替代；乙基、炔基亲核物的镁配位与溶剂效应如何合理入域。动态课完整展示乙基进攻羰基的两支电子对箭头。

## 2. 氢化与催化剂

净式：C20H30O2 + H2 → C20H32O2；进一步 +H2 → C20H34O2。后者现在有唯一连接图，只还原原炔位生成的烯键，其他多键保留。没有将全部可能过还原物混为该结构。

教学设定：95% 炔二醇转化；生成 H 的 2%（选择性）或 20%（过还原对照）进一步还原；未反应气体保留。Pd/CaCO3/Pb/喹啉库存分别保存，活性 1→0.9 为状态变量，不会凭活性下降删除金属原子。

没有对催化剂形成、Pd 表面结构、H2 解离吸附或脱附建立微观模型。教学页说明表面催化概念，展示净 H 原子归属，**不提供伪造的离子弯箭或 TS**。局部 syn 倾向与最终全反式身份分开；hydroxenin 目录未指定的完整立体构型继续未指定。

需审核：自由羟基/水/乙醚/喹啉的实际介质作用；过还原位点选择；更多双键还原和异构化是否应进入拒绝域；载体/修饰物的表示。当前投料不是工业 Lindlar 制备规范。

## 3. 中间体分配与乙酰化

过滤与“98% H → 下一工段、其他物料 → 废料”的分配是合并理想工序，不宣称过滤器本身能除溶剂与水。所有去除组分保留在废流。转入乙酰化只含 H、乙酸酐、吡啶、对二甲苯，仍运行已有 E01/E02 RK4 竞争模型，不用固定产率替代既有反应。

需要后续真实工艺：催化剂滤饼持液、溶剂交换、干燥、残余炔/过还原物的分配与检验。理想分离是工程连通阶段的限制，不能当作已实现工业分离。

## 4. E03、立体身份与晶体

净式 C22H34O3 → C22H32O2 + H2O 有元素守恒。游戏当前以90%复合净进度及80:20目标/单Z分配说明后续净变化。前一中间体有未指定构型，因此并非实验预测的产物分布。

目标结构验证四个侧链双键 E。新增单 Z 比较体只翻转其中一个明确双键，RDKit / CDK 身份不同；不将它命名为未核实的位置异构体，也不代表全部 cis 池。晶体分配90%全反式与1%单Z，母液保留其余物料。质量门>=99%仅覆盖这两种教学异构体。

E03 页仅展示原子守恒的复合净端点映射，明确不表示基元路径。逐步质子转移、碳正离子/共振、双键迁移、可能副反应以及E/Z调节尚未审核和展开。这是 D18 教学的开放项，不标为完整机理完成。

## 5. 参数和依据

既有 EP2225193B1 支持路线顺序背景，Coumans 2018 支持相关乙酰化研究；它们不为本版所有教学参数背书。本轮没有补充新的工业参数来源。所有3D构象和插值非优化路径，元素/图自动检查也不等于专家审阅。

下一轮优先审阅竞争模型、氢化位点和 E03 路径，建立来源→条件→模型域→测试案例对应，再决定哪些参数可以校准。
