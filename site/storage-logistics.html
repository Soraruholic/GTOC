维生素 A 的分段仓储
维生素 A 不是一根把所有工序串起来的管道。C5/C8/C10、C6、C14、偶联、部分加氢、乙酰化和结晶各自拥有原料缓冲、残余仓和质量交接点。
原生上游与气体
丙酮、甲醛、乙炔、氢气等以身份白名单进入各自源仓；压力/温度资格需另建合同；当前标签与 FluidRegistry 映射不包含完整压力联锁。
质量交接与隔离（设计要求）
只有通过上一工段的残余、酸碱和纯度门槛，才可进入下一工段缓冲。α/β 或 E/Z 未定的物料进入隔离仓，不能被重命名成全反式。
副产物去向（设计要求）
盐水、催化剂滤饼、母液、尾气和不合格批次都有独立仓位。任何没有去向的产物都会让工厂停在诊断状态。
储罐不是反应器
储罐只保存和转移物料；浓度、选择性、分离、热负荷和 EU 仍由工艺模块显式提供，不能在存储层自动推断。



接入能力：当前代码与设计目标分开读
现有：外部管道向 OC 端口推送
StorageTile 提供 IFluidHandler.fill，按明确注册映射接收入料，先保留 pending request，再交世界服务入账。它目前不提供产品 drain，也不主动抽空任意外部储罐。真实来源保存与断电原子性仍需验收。
设计：GT / EnderIO 的独立路由
管道负责搬运和过滤。接收容量、批次来源、压力资格、工艺放行要由各自合同证明。当前储存层的 GAS 字段只是标签，并未完整实现压力联锁。
现有固体端口与后续身份合同
IInventory 提供一个待入账槽；当前催化核心使用明确的 OC 物品身份。通用 meta / NBT 白名单尚需实现，不能说任何原生物品均已兼容。“一个物品”也不会自动解释成 mol。



游戏中的一键流程
  1. /ocfactory create ester start 或 /ocfactory create vitamin_a start：建立蓝图并启动调度，不创造物料。
  2. /ocfactory status：查看节点、路线、阶段和运行状态。
  3. /ocfactory diagnose <factory UUID>：查看每种原料已进料量、缺料或缓冲满槽原因。
  4. 将 GT 储罐 / 输入仓 / 物品仓通过已批准的端口和过滤器接入；自动调度器每个周期最多转移声明的上限。
  5. 右键设备查看工艺状态；满槽、断线、卸载和重启后先看诊断，再恢复。重复请求只返回原回执。
边界：网页动画、蓝图和命令都不能凭空生成乙酸、乙醇、水、氢气或维生素 A。真人验收仍需确认 GT 机器形成、管道方向、外部端点和实际流体注册名。



ONE-CLICK PHYSICAL LAYOUT
一键命令会生成哪些可见装置？
/ocfactory create … start 在账本提交后，会在玩家附近的连续空位放置一排 OC 存储 / 进料端口。每个端口只绑定一个账本节点：源仓、独立进料缓冲、反应/分离缓冲、产品、残余、废水和尾气不会共用一个无标签容器。放置失败会保留蓝图并显示空位坐标，不会覆盖已有方块。
装置连接方式游戏内表现
液体 / 气体源端口GT IFluidHandler；精确 FluidRegistry 身份和相态管道可填充；入口先显示“待确认”，随后由服务器唯一账本入账
固体源端口Forge IInventory；当前明确支持 OC 催化核心；通用 meta / NBT 合同待补输入仓/物品管道放入催化剂或辅料；入账前物品留在端口，满时回压
产品 / 残余端口账本输出节点和质量隔离目前只读显示容量、身份、批次和阻塞原因；实际成品出口仍受 GT 映射和质量凭证门控
右键 UI服务端只读状态包显示节点角色、相态、单位、容量、库存、待确认 request id、过滤器和恢复状态
恢复边界：管道接口是同步 Forge 调用，不能自行提供跨重启 exactly-once。OC 端口先持久化同一个 request id，再由 UnitService 写入账本；重启后重放同一请求只返回原收据。若未来接入任意 GT 外部储罐而无法提供来源检查点，系统必须保持 UNPROVEN / QUARANTINED，不能自动补料。



GTNH STORAGE STATION
从首批配料走向长期自动供料
GT 储罐 / Super Tank、EnderIO 储罐可作为外部来源候选，固体通过物品仓提供。每种原料独立过滤、计量和接收；共享的是管架空间，不是无标签的混合总管。
当前限制：调度器配齐首批后停在 CHARGED，没有把缓冲物料自动送入整条反应工艺、消耗本批并重新建立下一批需求。全线反复生产还需要工艺接料、输出预留、旁流清空或隔离以及批次切换合同。现版一键命令放置 OC 端口，不会生成完整 GT 多方块工厂。
本地源码核对的 GT 普通不锈钢流体管编号为 5142；EnderIO 储罐默认每次推送 100 mB。数值是版本相关的搬运规则，不是 OC 化学速率。真实装置、过滤方向、断线和世界重启由玩家集中验收。
