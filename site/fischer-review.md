## 逐项审阅表

| 项目 | 当前自检结论 | 专家意见/修订 |
|---|---|---|
| 名称 | Fischer esterification；采用“Fischer 酯化”，避免 Fisher 拼写 | 待填 |
| 机理分类 | 酸催化亲核酰基取代；加成—消除路径 | 待填 |
| 羰基质子化 | 孤对 → 质子，同时水合氢的 O–H 键电子回到介质氧 | 待填 |
| 亲核加成 | 醇氧 → 酰基碳；C=O π 电子 → 原羰基氧，避免五价碳 | 待填 |
| 质子转移 | 用水/水合氢离子展开为两次步骤，不画无介质的跨氧“跳氢” | 待填 |
| 离去 | –OH2+ 以中性水离去，原羰基氧孤对重建 C=O | 待填 |
| 酸再生 | 最后去质子化，再生酸的化学作用；不宣称同一编号 H 必须循环 | 待填 |
| 原子身份 | 本条映射 O3 进入烷氧基、O2 进入水；提示酸中氧交换可改变标记分布 | 待填 |
| 电荷/孤对/价态 | 七状态程序验证；总电荷 +1；O 的键级和电荷/孤对匹配 | 待填 |
| 可逆性/平衡 | 催化改变通向平衡的速率；示例 K=4 属游戏参数，不是真实常数 | 待填 |
| 三维尺度 | 手工构型可有非物理接触；不用于读键长、能量、时间或过渡态 | 待填 |
| 教学反馈 | 错误选项说明具体原子的角色；正确答案给出电子记账理由 | 待填 |
