# C6 供应候选模型与教学：独立审阅包

版本 0.4.0-va-supply-alpha1；独立化学审核 **pending**。本文件列出待审问题，没有声称已经联系或获得专家认可。

## 净物料与参数

1. 2 acetone → diacetone alcohol；丙酮起始量的 0.025 作为副反应进度，消耗两倍丙酮。
2. acetone + formaldehyde → 4-hydroxybutan-2-one；剩余限制试剂的 90%。
3. hydroxybutanone → MVK + water；90% 脱水，98% MVK 理想回收。
4. MVK + acetylene + NaNH₂ + H₂O → C6H8O + NH₃ + NaOH；限制物的 90% 进入反应，95% 1,2 叔醇 / 5% 1,4 比较体。剩余 NaNH₂ 另行水解为 NH₃/NaOH。活化、加成与水解为分阶段复合净工序；液氨/溶剂、压力及工况尚未建立。
5. 98% 叔醇理想分配后，90% 进入水介导烯丙重排；Z/E 为 85:15；98% Z 回收至偶联进料。E 和未反应物保留。

所有分配与进度都属教学设定，85:15 只借用 EP2225193B1 背景描述。不能将其解释为平衡常数、普适选择性或真实工艺最佳参数。B01 聚合、B02 更多副反应、B03 炔丙竞争路线仍未建模。

B03 的最后连接图未指定 E/Z；游戏模型另行分配两种已登记异构体，箭推不产生一个经证明的 85:15 数值。三维只是示意关键帧，不是优化中间体、TS/IRC 或真实运动。

## 原生边界

1000 mB = 1 教学 mol 是模型单位政策。甲醛按 GT 登记组分处理，不推断为商业溶液；既有流体 density/temperature 数值不用于真实工程。GT 注册配方是游戏供给证据，不能用于化学参数拟合。
