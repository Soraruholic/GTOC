C14/C6 偶联工段：可逐步执行的实机验收

当前版本 0.4.0-va-darzens-alpha1。请用 Darzens 隔离实例；新 C14/C6 双支线按 最新手册 操作。下方较早版本与基线属于历史记录。

历史 v1 手册。当前测试服请使用 GTNH-OC 0.4.0 Chain (isolated test)，并以 串联手册 的新建 v2 数量为准。下述版本、客户端名称及 0.931 mol 基线用于回看旧批次，不能用于新建线验收。

历史版本：0.4.0-va-coupling-alpha1。环境：GTNH 2.9.0-beta-2 / Java 17–25。本段终点是 C20 炔二醇中间料。先前的乙酰化线仍保留，其上游所需部分加氢和工段交接尚未实现。

1. 使用本次隔离客户端

Prism 实例名称：GTNH-OC 0.4.0 Coupling (isolated test)。登录自己的正版账户，进入已配置的测试服。本机 SSH 隧道运行时，连接地址是 127.0.0.1:25566。实例尚未由自动化启动；实际窗口显示由你验收。

聊天栏执行 /occouple status，应看到版本 0.4.0-va-coupling-alpha1、服务状态、已有偶联线数量和世界事务序号。版本必须与服务器完全一致。短暂的 LOADING / SOLVING_FROZEN / COMMITTING_FROZEN 是处理中；QUARANTINED 需要查日志，不能删除账本。

旧实例保存为历史版本；连接更新后的测试服请使用本次实例。在新实例中仍可执行 /ocva status 操作原乙酰化线。

2. 放置八台设备并辨认界面

站在平坦空地，当前位置的南侧第三格开始、向东连续八格必须是已加载空气，下方建议有地面。朝向不影响命令。

/occouple place

记下返回的起点 x/y/z 和线 UUID。从西向东为以下设备；以右键标题为准，方块外观复用旧试验设备纹理。

偏移右键标题操作
x+0C6 干燥 / 投料选择一次夹具、干燥、C6 入活化釜
x+1双活化釜双活化、收气、合并进料
x+2乙烷收集缓冲收集活化釜和后处理罐的乙烷
x+3C14 计量罐合并 C14 / 已活化 C6 进料
x+4C14/C6 偶联釜偶联 95% 进度
x+5酸性后处理后处理、收气、教学分离
x+6C20 中间料分析只读产物数量、工序曲线、全线状态
x+7废液 / 残余缓冲只读未反应物、酸、水、溶剂及盐

每台都有“本机库存 / 工序轨迹 / 全线诊断”三个页签，列表可翻页，曲线可切换有机组分、气体和盐、水分。只有产线所有者可用界面，装载开发夹具另需管理员权限。八台机器必须保持齐全且区块已加载。

3. 一次装料具体得到什么

右键第 0 台，选择 痕量水夹具。每条线只能选择一次夹具；切换实验条件时应放置新线。

初始设备物料数量 / mol
0C6-Z / 乙醚 / 水1 / 5 / 0.02
1EtMgBr 有效组分 / 乙醚2.2 / 3
3C14 醛 / 乙醚1 / 2
5硫酸形式投料 / 水1.5 / 5

“湿料夹具”仅将第 0 台水改为 0.3 mol；“超域水夹具”改为 1.2 mol。后处理水在第 5 台隔离保存，不会在双活化之前接触试剂。

这批物料由开发入口写入共享世界账本，带 fixture=true 标记。不需要桶、单元、空瓶或自行寻找精确 mB。本段尚无 GT 管道 / IFluidHandler / 容器导入接口，也未开放生存制造配方。mol 不应在未知密度时换算为 mB。

4. 跑通干燥基线批次

每次点击后，先等事务结束、工序号增加或按钮状态刷新，再关闭界面移动到下一台。按钮禁用时悬停查看具体原因。

顺序设备与按钮应观察到的变化
1第 0 台：痕量水夹具阶段 LOADED；第 0 台液流有 0.02 mol 水
2第 0 台：干燥吸水0.02 mol 水转入“吸附”库存；液流水为 0；容量尚余 0.48 mol
3第 0 台：C6 入活化釜阶段 CHARGED；C6 和 5 mol 乙醚进入第 1 台；吸附水留在第 0 台
4第 1 台：双活化阶段 ACTIVATED；C6 双活化物 1 mol，剩余 EtMgBr 0.2 mol，气体乙烷 2 mol
5第 2 台：收集乙烷第 2 台气体 2 mol；第 1 台气体清空
6第 3 台：合并偶联进料阶段 COMBINED；第 4 台接收活化液和 C14 进料，合计乙醚 10 mol
7第 4 台：偶联 95% 进度阶段 COUPLED；C20 双镁醇盐 0.95 mol，C14 和 C6 双活化物各残余 0.05 mol
8第 5 台：酸性后处理阶段 WORKED_UP；C20 炔二醇 0.95 mol，酸耗 1.1 mol，MgBr₂ 与 MgSO₄ 各 1.1 mol；残余 EtMgBr 转为额外 0.2 mol 乙烷
9第 2 或第 5 台：收集乙烷第 2 台累计 2.2 mol；两台反应设备中的待收气体均为 0
10第 5 台：教学分离阶段 SEPARATED；检查第 6、7 台与下面的数量表

本工段没有等待反应计时器：一次点击提交一个计量工序。事务通常经过数个服务器 tick，实际取决于负载和磁盘；以 UI 状态为准。没有必要使用加速按钮。曲线横轴是工序序号，不能读成秒。

第 6 台的混合物不是纯品；没有经过氢化、重排、异构体分离或药用质量认证。95% 偶联反应进度、98% 目标物分配以及 1% 水/乙醚夹带是教学参数。盐保持形式溶解组分，不能把它们理解为已分离的结晶。

产品留在第 6 台对应的账本库存，没有 bottle 操作、背包占位要求或自动掉落物。当前没有从该设备向乙酰化线转移的入口；不能把 C20 炔二醇直接当作 hydroxenin。

每组用一条新线，避免混入上一批库存；最多 8 条偶联线，服务端 QA 占一条。

案例操作差异双活化之后最终收集 C20 / mol

湿料案例的 EtMgBr 已在活化阶段用尽，因此酸性后处理没有新增乙烷：第 9 步按钮显示“没有待收集乙烷”时直接进入教学分离。三种成功案例的累计乙烷最终均为 2.2 mol，但产生工序不同。湿料先干燥可以移除 0.3 mol 水并恢复基线结果；这是本教学模型的结果，不等于真实干燥工艺的性能保证。

7. 检查 UI 和学习反馈

逐台右键检查标题、数量和分页，尤其第 2 台应显示气体，第 0 台应显示吸附水。在曲线页切换三组曲线，悬停查看指定工序的数值。不要用流动水总量判断活化釜含水，因为全线总量包含隔离的后处理水。

网页 C14/C6 偶联工场 包含水失活、两次脱质子、偶联、两次质子化的 5 条机理。每条都可以选原子、观察形式电荷和孤对、尝试错误 / 正确电子供体答案。三维不可用时，二维和文字仍可操作。

由你补充客户端验收：三个 GUI 缩放档下是否有文字/按钮重叠；八台是否均能打开；禁用原因是否看清；曲线悬停是否可读。浏览器验收和 FakePlayer 服务端验收不替代这一项。

8. 重复点击、关闭、断线与重启

连续点击同一按钮不能重复装料或重复反应。协议绑定真实连接玩家、窗口、会话、请求序号和库存版本。求解之后、写盘之前若界面关闭、距离超限或设备不完整，候选事务丢弃；若写盘已经开始，则以恢复后权威账本与回执为准，不能假定关闭就是取消。

重新进服后执行 /occouple status，核对线 UUID、阶段与坐标，右键检查吸附水、气体、产物和废液。不要为了“恢复机器”再次创建并装料。

若块引用意外丢失，原所有者在原维度执行 /occouple repair <线UUID>。只恢复原坐标的空位，不覆盖其他方块，也不创建化学数量。先加载原区块。设备目前不可正常挖掘或搬迁。

9. 报告与存档版本

/occouple report 将全 v2 账本导出到服务器工作目录的 oc-coupling-world-report.json，包含原乙酰化线、新偶联线、回执和全部库存。/occouple qa 是管理员的保留区 Forge 验收，不是给普通玩家自动摆放产线；报告为 oc-coupling-live-qa.json。

原 v2.1 世界可读取。首次创建偶联线后共享权威文件升级为 v2.2；原乙酰化数据保留。降级不能仅换旧 JAR：旧版本会拒绝 v2.2。若确需回退，应离线恢复升级前经过验证的整个世界备份及匹配 JAR，不能手改 schema 或删掉 coupling 字段。

本版气体采用有上限的数量缓冲，未建压力 / EOS；反应热和热交换未建模。显示“未建模”不是零压力或零热量。

10. 通过标准与下一步

本轮人工通过要求：八机界面可用，干燥基线数值一致，湿料差异一致，超域拒绝明确，重新打开 / 进服后库存保留，原乙酰化线仍可查看。记录客户端版本、线 UUID、所选夹具、工序和异常现象即可。
