# C14/C6 双支线验收手册

本版 `0.4.0-va-darzens-alpha1`，推荐 Prism 实例 **GTNH-OC 0.4.0 Darzens (isolated test)**。这是教学开发服：管理员放置设备，C6 碳源通过真实 GT 标准单元消费，β-紫罗兰酮、氯乙酸甲酯与各类辅料暂由明确标记的夹具输入。没有宣称完整生存闭环。

## 1. 新建五个工段

保留已有批次，不在旧线重复装料。找一处足够的空地，所有设备放在相近、已加载的区块内。每条命令会从玩家位置向南偏移 3 格，沿 +X 放置一排；执行下一条前换到另一排，等待 `/ocdarzens status` 的账本状态恢复 READY 或 COMMITTED。不要站在将被放置的空位内。

1. `/ocva place`：创建乙酰化六机线，记下 UUID **V**。
2. 换空排，`/occouple place`：创建偶联八机线，记下 UUID **C**。
3. 换空排，`/occhain place C V`：用真实 UUID 替换 C、V，创建后段六机线。
4. 换空排，`/ocsupply place C`：创建 C6 六机线，记下 UUID **S**。
5. 换空排，`/ocdarzens place S`：在进料前绑定 C14 六机线，记下 UUID **A**。

每排从西到东编号 0 起。每台均右键打开 UI，含“本机库存”“工序轨迹”“全线 / 诊断”。曲线横轴为已提交工序，纵轴为 mol；没有给净工序虚构反应时间、压力或热量。灰色按钮可悬停查看具体拒绝原因。

第五步把关联偶联线标为“双来源模式”。此后其原料夹具按钮以及 C6 分离机原先“交接 C6 / C14夹具”按钮均被禁用。必须从下面两条支线联合交接。

## 2. 生产 C6

原生单元的取得、名称与生产配方见 [C6 原生进料手册](supply-manual.html)。管理员可使用：

```text
/ocsupply givefeed acetone
/ocsupply givefeed fluid.formaldehyde
/ocsupply givefeed acetylene
```

每次把手中一堆拆成 **1 个单元**，右键 C6 第 0 台，点击“导入手持原生单元”。待手中变为空壳、库存增加后换下一种。每种 1,000 mB 按游戏约定为 1 教学 mol，并非真实密度换算。

依次操作：

| C6 设备 | 按钮顺序 |
|---|---|
| 0 原生进料站 | 三种导入确认后，“装载辅助夹具” |
| 1 羟醛 / 脱水釜 | “羟醛加成” → “脱水并分配 MVK” |
| 2 乙炔化釜 | “乙炔化 / 水解净工序” |
| 3 重排釜 | “烯丙基重排净工序” |
| 4 分离机 | “分配 Z-C6”；停在 **SEPARATED** |

每次点击等待世界账本确认，通常无需人为等待化学计时。不要点击旧夹具交接。此时 Z-C6 约 **0.4737120161 mol**。

## 3. 生产 C14

| C14 设备 | 按钮顺序 | 应看到的结果 |
|---|---|---|
| 0 原料计量 | “装载标明来源的夹具” | β-紫罗兰酮 1、氯乙酸甲酯 1.1、甲醇钠 1.2、甲醇 2 mol；其他设备预置 NaOH 1、水 3、HCl 净当量 1.1 mol |
| 1 Darzens 釜 | “Darzens / 分配环氧酯” | 生成环氧酯 0.9 mol，0.882 mol 进入水解；盐、甲醇、剩余原料留在分流残余 |
| 2 水解釜 | “皂化环氧酯” | 环氧羧酸钠 0.8379 mol；保留未水解酯与多余碱 |
| 3 酸化后处理 | “酸化 / 中和残碱” → “脱羧净工序” → “共轭化净工序” | 中和残余 NaOH；CO₂ 0.796005 mol 入气体库存；C14 连接图与偶联输入一致 |
| 4 分离 / 交接 | “分配 C14” | C14 **0.70207641 mol**，阶段 SEPARATED |
| 4 分离 / 交接 | “C14 + C6 联合交接” | 两边各扣 **0.4737120161 mol**，偶联变 LOADED；本侧多余 C14 **0.2283643939 mol** 保留 |

进度 90%、95%、98% 都是未校准教学参数。分离是组分分配，不是已验证的蒸馏或萃取设备。不同阶段残余被分区记账，残余罐同一组分表不意味着已经混合发生中和；不可把未用强碱当无害废液。本版没有自动销毁物料。

联合交接同时核对两条来源、同一所有者与维度、阶段、库存、目标容量和设备完整性；它在同一份世界账本中提交。若任一条件不满足，两边都不扣料。重复点击不会再次投放。此动作还配置格氏试剂、溶剂与后处理辅料，因此仍需要管理员。

## 4. 偶联与后段到成品

偶联已经 LOADED，**不要再次装夹具**。按以下顺序：

1. 偶联 0：“C6 入活化釜”。
2. 偶联 1：“双活化”。
3. 偶联 2：“收集乙烷”。
4. 偶联 3：“合并偶联进料”；然后偶联 4：“偶联 95% 进度”。
5. 偶联 5：“酸性后处理”。
6. 偶联 2：再次“收集乙烷”。
7. 偶联 5：“教学分离”；目标产物随后出现在偶联 6 的库存。
8. 后段 0：“按进料配辅料” → “接收 C20 物流”；后续按钮按 [后段手册](chain-manual.html)执行部分加氢、过滤、交接乙酰化。
9. 乙酰化仍使用 3,600 模型秒。可以点击“自动本批”并切换加速，或重复“推进 60 s”；其余新增 C14/C6 工序只需等待账本确认。加速改变推进速度，不改变模型反应常数。
10. 后段接收乙酰化分离料、脱水/重排、结晶。预计全反式乙酸酯晶体约 **0.1644341857 mol**，仍在第 4 台固体库存。

本轮没有新增成品物品导出或连续再批。不要执行清账、删除世界账本或反复创建新线代替再批。样品引用也不等于库存已经导出。

## 5. 拒绝与重启验收

- C6 未分离时尝试联合交接：应提示等待，C14 不减少。
- 新偶联线尝试旧原料夹具：应提示双来源限制。
- 联合交接后再次点击：按钮禁用，源余量与偶联库存不增加。
- 一次操作受理后关闭窗口：提交前绑定改变会取消；已落盘则以账本确认结果为准。重新打开查看实际阶段，不按画面延迟盲目重复。
- 重启后通过 `/ocdarzens status` 找回同一 UUID 与阶段。设备引用丢失可用 `/ocdarzens repair A` 恢复原空位，不能搬迁或覆盖其他方块。
- 每个世界目前最多 8 条 C14、8 条 C6、8 条后段线，并受偶联 8 条上限约束。这是保留历史后的有界开发额度，不是连续批次功能。

客户端渲染由玩家手动验收；开发验证另覆盖真实 Forge 容器请求、原生单元消费、存档恢复和守恒。
