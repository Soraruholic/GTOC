# 维生素 A 首轮 D1–D10 执行记录

发布日期：2026-10-03。版本：0.4.0-va-slice-alpha1。

本轮交付一条六设备的 hydroxenin 乙酰化教学切片，目标是让库存、实际积分、竞争反应、分离与教学一起落地。没有将原生全线或维生素 A 成品标作完成。

## 1. 交付内容

- 运行时物料审计：1476 流体、171 配方表、2339 条相关配方，无导出错误。乙醇的真实名为 bioethanol、甲醛为 fluid.formaldehyde、乙酸酐为 molten.aceticanhydride。含溴矿物电解已确认，矿物 / 机器的生存获取闭环仍待核实；吡啶与对二甲苯缺原生映射。
- 37 项版本化组分目录：CDK 结构身份、显式立体策略、形式盐、参数空值与能力范围。
- 六机器共享 v2 世界权威：多组分液固库存、反应热和显热账、单写入器、主线程验证与回执。保留旧 v1 产线和 M2 样品服务。
- E01/E02 竞争乙酰化、乙酸副产物、过滤器持液、分离残余、湿基中间料质量门与一次混合物流回收。
- 六类右键界面：实际库存、五组分 61 点轨迹、mol / mol·L⁻¹、暂停、60 / 300 模型秒速度、物流和能量历史。
- 包装以同账本样品为权威，背包纸张仅为可补发引用。实际背包满、重放、遗失引用均不生成第二份物料。
- E01/E02 完整骨架机理课：78 / 83 显式原子、各六帧、原子选择、电子供体反馈、成对电子箭头、二维 / WebGL 回退及化学审阅包。
- 隔离 Prism 实例、测试服部署、源码快照、可重建静态站及十节人工验收手册。

## 2. 验证证据与限度

完整 Gradle build、格式检查、静态检查和 64 项 JUnit 通过；原有化学检查覆盖 36 条轨迹 / 360000 步。新增测试含五个落盘故障窗口、重复 / 冲突回执、身份 / revision 拒绝、并行第二写入器拒绝、损坏隔离、满容量与 16 条线的有界串行核心负载。

Java 的一秒 RK4 与独立 SciPy DOP853 在 303、323、343 K 三组条件下逐点对照。最大绝对误差约 3.97e-10 mol；步长收敛也通过。这证明指定教学方程的数值一致性，不证明实际化学速率正确。

真实 Forge 测试使用合成玩家、真实机器方块和 Container，不操作 Minecraft 客户端桌面。初次完整批次构建 SHA 为 `750b761b26ee577443d7d93f30d9292d727ad995d0afae8601cd03100ccafcb3`；最终构建增加绑定修复与明确的区块生命周期检查，SHA 为 `a9aa431f1cd98e0c9135fdb7e8a11ebdebe230019b5e9e742ff382398c65a2be`。已直接比对两份服务器 JAR，30 个核心化学 / 持久化 / 容器 / 网络 / UI 类字节完全一致；最终服务重启后整线 JSON 精确一致，并通过实际区块卸载 / 重载检查。证据中保留两次构建身份，没有把先前构建的首次操作伪装成最终构建重新执行。

16 条已包装完整线的权威 JSON 约 253 KB，单批 3600 模型秒的本机热身后核心求解约 10–15 ms。这是串行 CPU 核心测试，不是服务器全 tick 负载、多人 TPS 或长期内存测试。

运行时配方重启比对中，41 条 Eye of Harmony 配方的输出列表顺序发生变化，集合与数量一致；其余 2287 个唯一内容指纹保持相同。内容 hash 保留槽位顺序，不提供永久原生配方 UID。
