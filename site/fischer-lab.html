FISCHER ESTERIFICATION / AN ATOM-MAPPED LESSON

看懂一个酯，是怎样形成的。

Fischer 酯化是酸催化的亲核酰基取代。先活化羰基，经历四面体中间体，再让水离去。跟踪三个氧的身份，比背诵“酸脱羟基、醇脱氢”更能解释电子为什么这样移动。

    为什么要把质子转移展开？

    加成后的醇氧有三个单键而带正电。先让水取走它的质子，再通过水合氢离子将羧基 –OH 转为 –OH₂⁺，后者可作为水离去。本课把原来一笔带过的“质子转移”展开成两次电子记账。

    溶液中可有多枚水、醇和酸参与接力；这里选用一枚显式水，不声称这是唯一微观路径。催化循环再生酸的化学作用，真实体系不要求同一个编号的氢走完一圈。

    加快反应，为什么不等于改变平衡？

    催化降低通向平衡的动力学障碍，同时影响正逆方向。过量醇或移除水可改变组成驱动力；加酸本身不能保证更高的平衡转化率。网页批次模型的 K = 4 是游戏教学参数，不能当成此真实反应在任意温度下的常数。

    逆向水解涉及相反的酰基取代通道。动画倒放能帮助核对键与原子，却没有给出活化自由能、速率常数、溶剂效应或实际产率。

    氧的身份，如何用实验检验？

    经典醇氧同位素标记支持：醇的氧进入酯的烷氧基连接。此课的 O₃→酯、O₂→水是一条具体映射路径。酸催化条件下可发生氧交换；不能把一次净映射扩展为所有条件与时间尺度下的唯一同位素分布。

    机理图是可检验的化学解释。相同分子式、自动原子映射或漂亮的三维路径，都不能单独证明某个中间体真实存在。

    无脚本阅读 · 七个状态的完整说明

    0 · 反应物与酸性介质

    乙酸的羰基氧 O₁ 接受水合氢离子的一枚质子。电子箭头由氧的孤对出发；同时原 O水–H 键的电子回到水氧，避免让氢形成两根完整共价键。

    注意：箭头代表电子对，不是正质子沿箭头移动。

    O₁ 孤对 → H催，形成 O₁–H催；O水–H催 键电子 → O水

    1 · 羰基氧被质子化

    质子化提高羰基碳的亲电性。乙醇 O₃ 的孤对进攻 C*，同时 C=O₁ 的 π 电子退回 O₁。两个箭头属于同一个加成步骤，不能只加键而让碳出现五个键级。

    注意：必须同时降低 C=O 键级，保持 C 的八隅体。

    O₃ 孤对 → C*，形成 C*–O₃；C*=O₁ 的 π 电子 → O₁

    2 · 亲核加成：四面体氧鎓中间体

    O₃ 已连接 C*、乙基和氢，三个单键使其带 +1。水作碱移走 H醇，O₃–H 的键电子回到 O₃；这一帧明确展示溶剂的作用。

    注意：不要直接画成未经说明的分子内质子跳跃。

    水氧孤对 → H醇；O₃–H醇 键电子 → O₃

    3 · 水移走醇氧上的质子

    中性四面体中间体的 O₂–H 仍是差的离去基。水合氢离子把刚接走的质子交给 O₂，得到连接 C* 的 –OH₂⁺。质子转移在溶液中可由多分子网络参与，这里只展开一条记账闭合的水接力。

    注意：离去之前把 –OH 变为 –OH₂⁺，不能默认排出 OH⁻。

    O₂ 孤对 → 水合氢离子的 H醇；O水–H醇 键电子 → O水

    4 · 羧基羟氧接受质子

    O₁ 的孤对重建羰基 π 键，同时 C*–O₂ 断裂、键电子归 O₂，离去的是中性水。O₁ 仍连着 H催，因此产物暂为质子化酯。

    注意：形成羰基与断 C–O 键协同记账，不能把碳画成五价。

    O₁ 孤对 → C*–O₁，重建 π 键；C*–O₂ 键电子 → O₂，水离去

    5 · 羰基重建，水离去

    水移走 O₁ 的 H催，O–H 键电子返回 O₁，得到中性乙酸乙酯并再生水合氢离子。催化剂加速可逆通道，不改变给定条件下的热力学平衡常数。

    注意：再生的是酸催化能力；真实溶液中的质子会交换，不必是同一编号的氢。

    水氧孤对 → H催；O₁–H催 键电子 → O₁

    6 · 酯与再生的酸催化剂

    约去中间体和同型酸催化剂，净反应为乙酸 + 乙醇 ⇌ 乙酸乙酯 + 水。O₃ 保留为酯的烷氧基氧；此处 O₂ 进入水。水解可沿相反的化学步骤发生，但倒放教学动画不是水解速率计算。

    注意：本条路径不证明酸中两个氧在长时间同位素交换中永不交换。

    酯与再生的酸催化剂

    约去中间体和同型酸催化剂，净反应为乙酸 + 乙醇 ⇌ 乙酸乙酯 + 水。O₃ 保留为酯的烷氧基氧；此处 O₂ 进入水。水解可沿相反的化学步骤发生，但倒放教学动画不是水解速率计算。

    本条路径不证明酸中两个氧在长时间同位素交换中永不交换。
