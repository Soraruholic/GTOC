维生素 A · 单元操作级

186 个旧端点全部对应可见设施；展开后 491 个布局节点、568 条连接。数量包含计量、容器、公用系统与检测/隔离职责，不是制造成本清单。

  1. 来源与计量：专用储罐 / 气源 / 固体料仓 → 独立计量与截止 → 设备专用入口。混合配方如甲醛溶液要保存浓度、水和稳定剂，不能把它当作纯气体。
  2. 废物流：设备出口 → 独立收集罐 / 气体容器 / 滤饼桶 → 检测与批准闸门 → 处理前隔离或批准移交。含金属、反应性、有机和普通盐水之间没有默认合流。
  3. 公用系统：循环介质储箱、泵和换热机组画为成套设备，补充罐、排污罐和电源单独落位。供回闭环不产生能量；冷源、热源、流量和耗电合同缺失时不许认定可生产。
  4. 中间料和产品：工艺设备保留本机持料；长时间等待或两支线汇合用显式缓冲解耦。产品出口和排空 / 不合格出口分开，任何回收品重新鉴定后才返用。
  5. 布局约束：围护与排液区域、干燥区、可燃气区、金属废物区和维护通道分别规划。架空管路不等于液体会自行流动；需泵、压差、流量和 GT 接口方向验证。

现在三维图表达了所有旧端点的物理设施职责，但它仍是候选装置布置。实际 GT 多方块、泵、仓容、完整原料供应、废物处理化学和整线自动调度尚未全部实装。图形碰撞检查也不能代替防火间距、设备强度或压降计算。

“夹具”是测试来源，不是一种化学耗材

这里的词来自软件工程 test fixture，指为了复现测试而预先设置的数据或条件。当前部分按钮会直接往 OC 账本加入一组确定的物料，没有扣除玩家背包或储罐。它不是机械夹紧装置，也不是名叫“夹具”的真实化学试剂。

代码中已查到的例子实际角色生存模式应怎样体现

OC 催化核心物品当前存储接口的测试物品，不代表所有工业催化剂保留为测试物品；未来分别增加有身份、负载、活性与寿命的催化材料
建议界面用词：“装载辅料夹具”改为“加载测试预置（不会扣仓）”，并显示每项物料和测试来源。生存模式使用“从连接仓库配料”；催化剂、试剂和溶剂各有真实数量。这里说明当前代码行为，尚未修改游戏按钮与旧存档标志。

生物产线最值得先补哪几段？

第一优先：糖源 → 乙醇 → 合格溶剂

农业储仓、糖化、营养配料、种子罐、发酵罐、冷却、CO₂ 收集、固液分离、蒸馏与脱水。产物除乙醇还有水、菌体、残糖、杂质和废液。发酵乙醇可供酯化，也可作为乙醚候选的前体。

第二优先：ABE 发酵供丙酮

糖类由梭菌体系进入酸生成与溶剂生成阶段，得到丙酮、丁醇、乙醇及旁流。已读动力学文献明确包含底物/产物抑制；不能把纯糖直接定比拆为三种溶剂。需要菌种、灭菌、厌氧条件和独立分离模型。

文献与边界

第三优先：生物质 → 糠醛平台

半纤维素来源、预处理、戊糖脱水与糠醛回收，后接呋喃/THF 催化支线。预处理抑制物、酸液与腐殖质固体都要入账。THF 的工艺适用性与替代乙醚能力另外验证。

植物来源研究

生物路线应提供新玩法：菌种状态、污染、糖抑制、营养与冷却瓶颈、连续补料和副产物利用。它们仍需要无机营养、电力、水与废物处理，不是免费原料生成器。

下一步按可玩闭环交付

  1. 逐股物流合同：给所有来源、批次缓冲和接收端指定真实身份、容量、计量基准、相容性、库存版本与过滤器；所有未知值拒绝开批，旧测试库存保持来源。
  2. 一次扣账与输出预留：验证全部输入、催化材料、溶剂和公用条件；预留完整混合输出和各旁流；断线重试不重复扣料，满槽时保留原批次。
  3. 乙酸乙酯先闭合：补酸催化剂或固体酸选型、来源仓、洗水、干燥介质和废液收集；再做有证据的溶剂回收。真实两批通过后复用接口到 VA。
  4. VA 优先消除高影响预置：先确认 p-xylene / ether 等映射，再完成 NaNH₂ 与 EtMgBr / 干溶剂供应。复杂钼络合物与有机磷助剂保持研究门槛，可并行评估植物柠檬醛入口以减少上游依赖。
  5. 第三线与生物线：保留木材干馏平台，新增农业乙醇作为优先生物支线；它直接补上木醋液路线乙醇产量不足的问题。
