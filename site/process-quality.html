连续标签回答“哪一相延续下来”

第一对被接受的两相按水摩尔分数区分；后续按两组组成与前一轮的总距离匹配为 L_org_lineage 和 L_aq_lineage。调换求解器数组顺序不改变保留物料。这些是组成连续标签，不能用于推断上层 / 下层或密度。

旧第六次计算没有分出第二相，整个进料被返回。已用多起点 Gibbs 最小化、化学势一致性检查和组成延续修正；单改标签不能解决这个问题。求解归一化到 1 mol，已复核 10⁻⁶ 到 10³ 尺度。首轮没有接受两相时，保留整股并标 SINGLE_CANDIDATE，不能解读为已证明稳定单相；已有两相之后失去解则标 unresolved 并停止参考续算。

模型只接受 298.15–380 K 的数值支持域；不构成整个温区实验有效性的证明。独立多起点 TPD 检查没有找到显著负方向，仍非全局稳定性证明。未处理电解质、VLLE、气相乙酸缔合、沉降时间或机械夹带。ΔG/RT 的单位是 mol，不是分离热。

公开数据到底验证了什么

NIST/TRC 档案目前冻结了 53 条三元 tie-line：乙酸/乙酸乙酯/水与乙醇/乙酸乙酯/水，303.15–333.15 K、101 kPa。由于公开档案没有完整四元 tie-line，不能把论文标题直接写成“四元模型已验证”。未拟合 UNIFAC 的最大组分对数活度差 |Δln a|中位数 0.212875、最大 0.657444；合成 midpoint 挑战的端点 RMSE 0.05961、最大绝对误差 0.33508，均是模型审计指标而非游戏收率或实验误差证明。

03 / CERTIFY BEFORE EXPORT

能追溯的库存，还需要能证明的身份。

质量凭证从服务器世界账本派生，物品 NBT 只提供地址。当前示范批目标为 0.0258919603 mol，湿基质量分数 99.72299%，仍含单 Z 组分。这个比例来自模型分配，不能当作实测全反式纯度。

这批从哪里来

世界、产品、批次、所有者、目录版本、序号；C14 / C6 / 上游 / 后段的来源账、28 个原生进料回执及夹具标识。来源账按工段流转保留，同一物料可能跨段出现，不能把各段 imported 直接相加当作外部总进料。

它实际包含什么

完整液/固组成、目标 mol、湿基质量分数、所有非目标残余；目录声明的立体结构与证据状态分别记录。

已经实现的事务边界

  1. 主线程验证所有者及操作绑定，冻结世界快照；服务器策略核对凭证摘要、物料身份、量、纯度、残余、立体/来源审阅和单位换算。
  2. 单写入器把成品扣账与等量 outbox 预留一起提交到同一世界文件。请求 UUID 与完整参数绑定，同请求重发只返回原结果。
  3. RESERVED 在进入外部调用之前可取消，原子退回；已记录产品本版不开放第二次出口预留。
  4. 进入调用后标 CALL_ENTERED；恢复可进入 UNCERTAIN。禁止自动重发或退款；待真实接收端独立持久化协议完成再处理。

接收端原型已经到哪一步

新增 oc-durable-receiver-1 诊断接收盒：它有独立 writer lock、带校验的 CURRENT.receiver、request UUID 幂等回执、参数冲突拒绝和写入故障后的 fenced/reopen 行为。回执状态固定为 STAGED_NONSPENDABLE，不会创建 GT 库存、不会清除 OC 预留，也不授权 CONFIRM。

本版不实际发放 GT 成品。普通 IFluidHandler.fill 与 GT 容器保存不是 OC 单文件事务；当前没有安装到真实游戏存档的接收端验证器，因此 CONFIRM 仍会拒绝。原生映射采用精确注册项而非按名称/分子式猜测。正向扣账测试使用明确标注的测试纯品和测试映射，不代表真实成品已合格。

04 / READ THE EVIDENCE

两位 AI 专项审阅，检查到了哪一层？

有机化学 agent 独立检查 U07 六帧、40 个映射原子、总式/电荷和五次箭头键级变化，并把 α/β 连接结构与 PubChem 核对。物化 agent 独立重算物料守恒、化学势、尺度和 TPD 局部稳定性。它们与实现分工，但不保证模型错误独立；不是持证或真人专家签核。

U07 羟醛/E1cB 可以作为候选教学路径。U08 有酸促环化工艺先例，当前 80% 进度、α:β=30:70、95% 分配均为未标定假设；没有完整 U08 微观动画，尚不含 γ 和完整杂质谱。α/β 命名表示环内双键位置，α 另有未定手性中心。专利的特定溶剂/温度/浓酸条件不能直接移植成本游戏参数。

研究支线如何进入正式模型

量化端点、中间体、TS/IRC 与 AI 产物候选只进入审阅队列；目前有不连接库存的队列内核，尚无常驻量化/AI 推理服务。候选要附方法、条件、来源、结构和守恒检查；通过审阅后还必须显式更新版本化目录/模型及工程验收，才能由世界服务落账。任何候选都不能自己生成库存或决定游戏选择性。

下一步：让一条产线既可解释，也值得反复游玩

进入工场挑战：先用实际游戏场景比较纯度、回收与耗水。基础玩法与科学参考并行迭代；网页目标不是库存权限。

  1. 一个可信分离切片：53 条公开记录的来源冻结和未拟合端点对比已完成；现已冻结 303.15 K 乙醇/乙酸乙酯/水的 6 条校准、2 条固定验证集与门槛（数据已看过，非盲测）；下一步只在来源与参数可识别性通过后拟合。固定协议；四元标题没有原始四元 tie-line 时保持未验证，不能把三元数据冒充四元校准。
  2. 一条可玩的基础线：八设备新增只读「本批目标」的本地源码；网页使用 6–10 洗的现有场景做决策练习。接下来接单权威保管和模拟等级产品用途，再加入生存配方与有界工序预设；不能把研究未知项变成随机罚款。
  3. 一个有数据的热过程：用冻结 Cp 参考给未来有完整温度/组成的工序提供显热切片；反应、混合及分离热继续独立 unknown，暂不自动 EU。
  4. 一个可恢复的 GT 接收端：完成精确物料注册/元数据和单位换算审计，诊断回执原型已完成；下一步把物料保管、世界服务及只读界面接入同一权威，再评估普通 GT 容器的跨存档协议。
  5. 深化 U08 教学：从酸活化到成环、竞争脱质子的逐原子方案先做审阅和二维箭推，再优化三维端点；不能用插值动画冒充 TS/IRC。

真人验收与这些工作可以并行；不重复耗时操作来代替缺少的数据依据。
