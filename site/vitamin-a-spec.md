## 1. 决策与交付范围

建议实施“有限化学域、显式组分、多设备协同”的路线：复用现有身份、持久化与机器 UI 基础，把固定四组分乙酸乙酯试验线升级为可承载多反应、多相、盐与催化剂的化工组件，然后用 Roche 型 C14+C6 路线建立第一条复杂产线。目标是玩家能配料、调节、看到真实保留的杂质、回收溶剂并解释失败。

必须同时推进一个化学垂直切片，不能先花几个迭代只造通用框架。第一切片选 hydroxenin 的选择性乙酰化：文献依据较好，能够同时检验多组分竞争反应、酸副产物、分离、UI 曲线与质量门；临时中间体只用于开发夹具，不能据此宣布“从 GT 原料完成全线”。

完整终点的验收是：来自已核实生存配方的原料进入 OC；各设备留下物料、能量、模型版本与请求记录；未反应物、副产物、溶剂、金属盐、催化剂和母液都有去向；分离后产品满足明确的游戏质量规格；重启与重复请求不会复制或吞掉物料。总收率、能耗和纯度必须可从实际批次导出。

## 4. 目标身份与产品契约

目标 PubChem CID 638034；分子式 C22H32O2；InChIKey QGNJRVVDBSJHIZ-QHLGVNSISA-N [V06]。结构应明确四个侧链双键为 E。不能以分子式相同，把顺式异构体合并到全反式库存。

总样品中目标质量分数 w_target 与维生素 A 乙酸酯异构体池中全反式比例 f_trans 是不同分母。干基纯度必须注明排除了哪些溶剂，不可把干基结果伪装成湿料质量分数。分析仪读取模拟器真实组分可作为第一版游戏机制；未来测量噪声属于独立模型。

产品仍是带批次引用和成分的 OC 物品。只有原生材料存在、映射版本与质量契约通过时才输出对应 GT 材料。未反应物和未达标物料进入返工、母液或废物库存，不能消失。药典、食品级、药用级不属于本项目当前声明范围。

## 6. 全线工艺与候选前驱支线

### 6.1 β-紫罗兰酮支线 U01–U08

候选原料骨架为：丙酮+乙炔→C5 炔醇→C5 烯醇；乙酸甲酯 Claisen 缩合→乙酰乙酸甲酯；Carroll 增碳→C8 酮；再乙炔化→脱氢芳樟醇；Meyer–Schuster 重排→柠檬醛；与丙酮缩合→假紫罗兰酮；酸催化环化→β-紫罗兰酮。

U01–U06 是有结构和净式的候选供应链，尚未冻结为工业路线。特别是酯缩合的碱消耗/酸化、Carroll 前驱及操作域、Meyer–Schuster 与 Rupe 竞争、C5 半加氢和溶剂回收都要补原始工艺证据。U07/U08 有路线描述依据，但本轮尚未读到所引 Organic Syntheses 原始程序全文。α/β-紫罗兰酮必须有独立产物和分离模型。

### 6.2 C14 支线 A01–A04

氯乙酸与甲醇制氯乙酸甲酯；β-紫罗兰酮在碱参与下 Darzens 缩合形成环氧酸酯；皂化、酸化、脱羧及相应双键重排得到 C14 共轭醛 [V04]。关键检查是 C14 增碳位置、环氧酸中间体连接和共轭双键位置。

A04 是复合净过程，不能在箭推课中用一支箭直接表示全部事件。涉及盐、甲醇、CO2 的库存要展开；酸/碱后处理不能只写“workup”而省掉物流。C14 构型、转化选择性及储存降解尚需冻结。

### 6.3 C6 支线 B01–B04

候选 MVK 来源为丙酮与甲醛羟醛/脱水；MVK 与乙炔候选 1,2 加成先给叔醇。B01/B02 的聚合、自缩合、1,4 加成和介质条件需审查，不能宣称无副反应。

已读专利支持叔醇经烯丙基重排形成 3-甲基戊-2-烯-4-炔-1-醇异构体，选取适用的 Z 支线 [V02,V03]。专利中的约 85:15 属于所述条件，不是普适平衡常数。必须安排分离或有依据的选择性工艺，不以全部变为 Z 作为默认。

### 6.4 干燥、双活化和 C14+C6 偶联 C01–C04

溶剂、C6、设备水分必须进入同一账本；控制惰性气体和排气。两当量乙基溴化镁分别消耗 OH 与端炔 H，乙烷进入头空间和气体收集；炔基对 C14 醛加成形成新 C–C 键；酸性后处理得到 C20 炔二醇 [V02]。

本规格以有机镁有效组分表示反应能力，不声称存在唯一的孤立二镁共价分子。溶剂化、聚集态、Schlenk 平衡超出第一版；“MgBr2 + MgSO4”是便于守恒的形式盐分配，真实水相离子物种由后续电解质模型决定。水分造成按当量失活，同时影响放热、气体与分相。

### 6.5 后段 D01–E03 与纯化

C20 炔二醇部分加氢得到 hydroxenin；过滤催化剂；使用乙酸酐选择性乙酰化伯羟基，保留二乙酰化竞争和乙酸；脱水/烯丙基重排与构型调节形成视黄醇乙酸酯异构体池；纯化、结晶、过滤和干燥获得满足游戏规格的全反式产品 [V01,V02]。

必须把不希望的进一步加氢、催化剂夹带、热/光/氧影响和母液保留列为明确模型边界。D02 当前只有过度还原分子式示例，尚未定义唯一产物图，不允许以该类别直接满足正式产物规则。

精馏用于适用的溶剂/轻组分分离；不能假定热敏、高沸的维生素 A 产品适合任意高温蒸馏。结晶模型首先需要溶解度、异构体分配与温度数据；缺数据时只能用注明适用范围的经验回收曲线，不能显示虚构的相平衡精度。

## 8. 化工组件的形式化定义

定义 Unit = (Id, Version, Geometry, InventoryRefs, Ports, EquipmentState, ModelBinding, Policy, Revision)。设备不是配方按钮；它持有空间/能力/边界条件和库存引用。UnitModel 计算候选变化，WorldLedger 唯一决定提交。

### 8.1 Species 与 CompoundData

SpeciesKey = (canonicalGraphHash, normalizationVersion, stereoPolicy, isotopePolicy, charge)。分子式由图或经审核的形式组分构造，不允许名称更换而结构不变的隐式变种。未定构型不能冒充指定异构体。

CompoundData 独立保存 molarMass、elementVector、charge、heatCapacityModel、formationEnthalpy、vaporPressure、density、solubility、hazardGameProfile、sources、validDomain、uncertainty。未知值为 null，不能用零表示未知热容或蒸气压。版本迁移必须保持旧批次的计算来源。

有机镁、催化剂表面位和未知残渣使用不同种类的组分条目。未知残渣若缺元素组成，只能作为 unresolved bucket 保留原有已知元素向量，不能参与任意新反应或转成有价产品。

### 8.2 相态、持料与状态闭合

PhaseInventory = (phaseId, phaseKind, composition[n_i], modelRef)。phaseKind 为 gas/liquid/solid；liquid-1 和 liquid-2 可共存，水相/有机相是模型或 UI 根据组成给出的标签。slurry 是固液共存工况。n_i ≥ 0；空相不定义摩尔分数，UI 显示“无持料”。

对固定容积封闭釜，推荐存储 z = (U, V_vessel, n_total, equipmentState)，模型求 T、P 和 n_phase。若采用恒压可移动边界，则改用对应 H/P 闭合并计入体积功；不同时独立写死 T、P、V、n。必须声明头空间、液体体积模型与模型失败时的状态。

气体起步采用注明范围的理想气体，液体采用参考密度/热容及有依据的混合近似；电解质、有机镁和固体浆料不自动沿用当前四中性组分 UNIFAC。超域时返回具体 UnsupportedModel，不默默套理想体系出结果。

### 8.3 端口与物流

PortType 为 Material、Heat、ShaftWork、Signal。MaterialPort 保存方向、允许相态、连接介质、流量/压差能力、温压限值、过滤条件和库存引用。SignalPort 只能传设定值/测量，不能传送物料或能量。

MaterialStream = (source, sink, nDot_i[phase], hStream, T, P, modelVersion, receipt)。流动物流携带焓；容器保存内能或所声明状态势。材料由泵、阀、管道能力及两端容量限制，不能一次无时间成本瞬移完整批次。第一版可以使用显式有界流量的离散流，不实现完整 CFD。

端口请求不是玩家提供一个任意分子列表；服务端从真实库存计算比例和可用量。UI 显示源、目标、相态、阀门、预期流量与拒绝原因。固体投料、滤饼和催化剂不通过液体管道伪装为同一接口。

### 8.4 守恒与数值合同

令 A 为元素矩阵，N 为计量矩阵，q 为电荷向量。每条化学变化要求 A·N = 0，电荷表示明确时 qᵀ·N = 0。当前 32 条形式净式的元素平衡已检查；这不构成所有展开离子/电子机理的电荷验证。

```text
dn/dt = F_in − F_out + N·ξdot
ξdot_j = V_reactive · r_j         r_j 的单位为 mol m⁻³ s⁻¹ 时
ξdot_j = extentRate_j            已给 mol s⁻¹ 时不再乘体积
dU/dt = Σ F_in h_in − Σ F_out h_out + Qdot − Wdot
n_new = n_old + Δn ;  n_new ≥ 0
A·Δn_system = A·Δn_boundary
```

若 U/h 包含一致的生成焓，不额外再加反应焓项。若只用显热基准，则明确加入 −ΣΔH_rxn ξdot 并使用一致基准；两种形式不得混合。夹套、加热器、气源是能量边界，控制器不是能量仓库。EU→J 是可配置的游戏标度，需要在报告中与化学物理模型分开列明。

求解器内部可使用浮点和自适应步长；负量、元素误差和能量残差超预算时缩步或拒绝，不能裁剪负数后偷偷损失质量。提交账本使用现有任意精度十进制契约；量化误差由显式残余寄存器/守恒约束处理，禁止简单逐组分四舍五入后宣称严格守恒。

容许误差以绝对+相对预算声明，分别记录 species、element、energy residual。具体门限在基准量级测试后冻结，不能以任意小数位美化守恒。求解未收敛不改变库存。

## 9. 反应、物性与专业引擎的分层

生产端使用确定性的 Java 核心，世界权威状态留在服务器；Python/RDKit/SciPy 作为离线结构审查、参考积分与参数拟合工具。独立可选 DWSIM/IDAES 研究模型用于有物性支持的子流程交叉核对，需先检查模型适用域与授权兼容。不会把一个开源流程软件直接当作全部有机反应的真实预言机。

ReactionModel = (stoichiometry, rateLaw, domain, competingPaths, catalystDependence, heatConvention, parameters, sources, verificationCases, version)。采用以下层级：

| 层级 | 允许行为 | 进入正式产品 gate 的条件 |
|---|---|---|
| 已校准模型 | 域内速率/平衡和选择性，报告残差与参数范围 | 有原始数据、拟合留出点、守恒与独立参考 |
| 有界经验工艺 | 特定 T/P/浓度/催化剂域内转化和分流 | 引用工况、插值边界与误差；不外推 |
| 教学模型 | 演示竞争、控制和因果趋势 | UI、产物与证据必须标教学，不称现实校准 |
| 未支持 | 允许储存/转运/观察；返回未知转化 | 不自动产生有价新物种，不捏造参数 |

同一批次的 confidence 不取模型平均值，而保留依赖链中最弱证据与每步版本。化学 AI 可建议候选图和反应类别，经过图合法性、原子映射、质量/电荷、条件、数据库与人工审核后才形成新的研究条目；不能在线临时发明可交易产品。

第一版不追求任意反应预测。玩家域外混合仍应有温度、相态、已有酸碱/水失活等受支持行为，并明确报告其余反应未支持；“未知”不等于化学惰性。

### 10.1 单元算子的最小数学合同

各设备的 Apply(snapshot, boundary, Δt) 返回 CandidateDelta、outlets、diagnostics，不直接写世界。以下表达式规定量纲和守恒结构，参数尚需按具体工艺冻结。

| 单元 | 最小模型 | 参数或数据缺失时的行为 |
|---|---|---|
| 夹套釜 | Qdot = UA(T_jacket − T_bulk)，与反应/进出料能量式共同积分 | UA 不是任意搅拌转速的同义词；使用标注教学的常数或拒绝真实热控预测 |
| 气液加氢 | 气→液传递 = kLa·V_L·(C_H2* − C_H2)；气液两账加减同量，反应另耗溶解氢 | 需溶解度与 kLa 依据；不把头空间有 H2 等同瞬时全转化 |
| 催化剂 | 固体质量/组成与有效活性 a 分开，0≤a≤1；失活过程保留载体与吸附物 | 活性可以作为经验状态，金属库存不能随“耗尽”消失 |
| 分液/萃取 | 各组分 n_i = n_i,1 + n_i,2 + n_i,hold；有热力学包时满足相间化学势条件 | 可用适用域内分配系数，但必须说明浓度基准，不能固定“洗掉 90%”冒充通用模型 |
| 过滤 | 固体捕集率 η_i∈[0,1]；n_feed = n_filtrate + n_cake + n_hold；滤饼含滞留液 | 未知孔径/粒度时使用标记的经验捕集模型，不能自动完全除金属 |
| 回收/精馏 | 顶、底和设备滞留量逐组分守恒；VLE 在支持域内求解，热负荷另账 | 缺二元参数时禁用精确相平衡标签；热敏组分受温度/停留域限制 |
| 结晶 | 总料 = 晶体 + 母液 + 滞留；采用 c_sat(T, solvent) 或有界经验回收，显式异构体分配 | 无溶解度/分配数据时不承诺精确纯度；模型保留夹液 |
| 真空/排气 | 泵/阀有界输送气体及能量；减压改变相平衡并消耗公用工程 | 出口堵塞时不偷偷删除气体；超出压力模型域暂停计算并提示 |

搅拌转速只在已声明的混合/传质关联式中影响 kLa、UA 或固体悬浮；需要桨型、釜径、黏度等资料才有可迁移的关联式。第一版可抽象为有限设备能力档，但不把“600 rpm”写成对所有釜都有效的化学条件。异构化、降解与分离是不同算子，不允许在分离器内部顺便改写物种身份。

### 10.2 批次、循环与产线分析

BatchReport 至少包括批次 ID、输入来源与是否夹具、各步模型/参数版本、投料与全部输出、起止库存差、气体/废液/滤饼/母液、质量门分母、热量与 EU 标度、运行/等待时间、拒绝事件、守恒残差和所有提交收据。

单步转化率 X、目标选择性 S、分离回收率 R 和全线孤立收率 Y 分开定义。C14+C6 主骨架的 Y 可按限制性片段的理论目标 mol 定义；前端完整原料经济性另统计含碳物料输入，不能把来自乙酸酐的两个碳忘掉。回收溶剂既是可重复使用的库存，也是有杂质和损失的物流，不给无限纯化收益。

循环用实际持料逐批推进，先测多批后杂质累积与排污量；首版不依赖理想零持料循环的代数瞬时收敛。记录 kg 合格品/模型小时、能耗/合格品、溶剂回收率和废物质量；游戏加速倍率与服务器计算性能另表，不能把加速后的墙钟产量当工业产能。

## 11. 调度、持久化与 GT 边界

现有 M2 样品账本与 PlantTile 自持库存不是同一套。迁移之前不能宣称产线已有跨设备恰好一次事务。新 UnitInventory 归 WorldLedger；TileEntity 只保存 UnitId 与绑定信息，容器 UI 引用服务端快照。

```text
主线程：验证真实玩家、距离、会话、revision、端口/容量 → 冻结输入快照
计算工作线程：在不可变快照上求解 → CandidateDelta + 残差/模型版本
主线程：重新校验版本与边界 → 预留 OC 两端 → 发提交请求
单写入器：事务日志与原子快照持久化 → CommitReceipt
主线程：应用已确认 revision → 解除预留 → 通知 UI
恢复：按 requestId/receipt 判断已提交、未提交或需隔离，禁止盲目重复
```

定时机器推进由服务端内部身份提交；所有来自客户端的控制请求绑定真实连接玩家，客户端不能指定任意玩家 UUID。断线不会撤销已经确认的化学结果；未确认 UI 不应提前显示物料已到账。

OC↔OC 转运由同一账本事务处理。GT 外部 IFluidHandler 的 drain/fill 和 OC 落盘不共享事务日志，无法凭普通两阶段调用实现跨两个存档的严格原子性。边界使用独立接收缓冲、外部调用记录、能检测时的补偿和不确定隔离；崩溃窗口不自动发第二份物料。若对方没有可查询幂等 token，需保守停机并明确人工对账边界。

GT 原料边界可继续限定无 NBT 的原生 FluidStack，复杂混合物先走 OC 管道。液体 mB→参考体积→mol 使用逐物种密度及参考温度映射；1000 mB=1 L 是本桥接约定。气体要声明标准状态或独立 mol/unit，固体 dust/item 也要逐项声明；不按同一液体公式换算。

## 14. 分子轨道与量化研究支线

适合教学的第一对象为简化羰基/炔基片段和乙酰化端点。用 RDKit 构象生成→可选 xTB 初筛→带版本与基组的 DFT 端点/中间体优化；记录溶剂、总电荷、自旋、多构象和频率检查。有机镁聚集态与表面催化不应由一个孤立分子 HOMO/LUMO 图解释全部反应。

轨道颜色表示波函数相位，不等于正负电荷；轨道表面阈值与方法需可查。Fukui/电荷分析只能作条件化辅助解释；没有校准不能由 HOMO–LUMO gap 直接推反应速率。端点优化不证明中间路径。

TS/IRC 必须在具体溶剂化、催化剂和微观模型选定后，确认鞍点与虚频方向，并检查 IRC 连接预期端点。它属于独立研究门，不阻塞第一条工程教学线；网页插值不能命名为 IRC。当前 ETKDG 三维仅用于结构观察。
