## 过程账与证据

Darzens：C13H20O + C3H5ClO2 + CH3NaO → C16H24O3 + CH4O + NaCl。

皂化：C16H24O3 + NaOH → C15H21NaO3 + CH4O。酸化：环氧羧酸钠 + HCl → 环氧酸 + NaCl；另外每 mol 剩余 NaOH 消耗 1 mol HCl，产生水和盐。脱羧：C15H22O3 → C14H22O + CO₂；再将非共轭连接异构体的一部分转为现有 C14 共轭醛。

没有预先认定完整微观脱羧/重排路径；原子映射只说明净端点。C14 目录仍不指定 E/Z，新增环氧中心不指定构型。合适的几何构象不能用于反推立体选择性。

默认批次得到 C14 0.70207641 mol；与原生 C6 支线交接 0.4737120161193 mol，两边同量，C14 余 0.2283643938807 mol。全反式晶体仍约 0.164434185724 mol：当前 C6 为限制支线，增加 C14 工段不会凭空增加后段产量。

新世界格式 2.5 仅在创建 C14 支线时升级；旧线保持原模型、原库存与历史。旧 JAR 拒绝新格式，不能通过降级程序读写带新工段的世界；回滚需成对恢复升级前世界备份与 JAR。保留历史后上调开发线路上限为 8，未删除任何旧线，未宣称解决连续批次。

## 机理教学与审核问题

新增 [C14 机理工场](darzens-lab.html#lesson)：Darzens 去质子化 → 加成 → SN2 关环；酯皂化加成 → 消除 → 质子转移；羧酸盐酸化。脱羧及共轭化使用明确标注的净端点。全部经过统一几何检查，三维离散切换，二维播放键/电荷变化。

需要独立化学审阅：特定 β-紫罗兰酮底物的 Darzens 立体关系；真实酸化/脱羧次序与中间体；未指定 C14 构型如何影响偶联；碱性环氧开环、卤代酯水解和底物聚合竞争；分离切分与原料残余的工艺可行性。当前没有把盐指定为沉淀，也没有热量、压力、真实溶剂化或工业产率校准。

## D28 冻结与 D29–D33

[原生来源审计](data/vitamin-a/darzens-feedstocks.json)包含当前加载的注册项、配方记录与输入哈希。该证据能说明选定注册/配方范围中有无物料，不证明世界生成、全科技树机器制作或完整生存成本。

优先路线冻结为 U01–U08 的分段候选：丙酮/乙炔 → C5 炔醇 → C5 烯醇；乙酸甲酯 → 乙酰乙酸甲酯；Carroll → C8 酮；再次乙炔化 → 脱氢芳樟醇；Meyer–Schuster → 柠檬醛；羟醛/脱水 → 假紫罗兰酮；环化与 α/β 分离 → β-紫罗兰酮。直接购入/找到原生 β-紫罗兰酮尚无确认依据。U03/U04 和 U06 是关键化学证据缺口，不以一条总反应配方跳过。

选择这个顺序的原因：β-紫罗兰酮在当前批次有余量，短期继续只加 C14 产能不能提高成品；可重复批次和真实辅料供应对可玩性更紧迫。回收必须保留杂质与 purge，不能用“回收百分比”直接产生纯溶剂。现有固定 10 L 乙酰化模型在真实体积/浓度模型接入前继续明确标注。
