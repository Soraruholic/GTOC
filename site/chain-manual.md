# C14/C6 到维生素 A 乙酸酯：串联教学产线验收

**当前版本 0.4.0-va-darzens-alpha1。请用 Darzens 隔离实例；新 C14/C6 双支线按 [最新手册](darzens-manual.html) 操作。下方较早版本与基线属于历史记录。**

**当前测试服为 0.4.0-va-supply-alpha1，请使用 GTNH-OC 0.4.0 Supply (isolated test)。原生 C6 支线按 [新版手册](supply-manual.html) 操作；本页保留旧 1 mol C6 夹具基线的步骤与数字。**

历史版本 **0.4.0-va-chain-alpha1**。GTNH 2.9.0-beta-2 / Java 17–25。使用 Prism 隔离实例 **GTNH-OC 0.4.0 Chain (isolated test)**。本机隧道运行时仍连接 `127.0.0.1:25566`。

当前可以从 C14/C6 开发夹具经偶联、部分加氢、现有乙酰化、复合净重排和结晶分配，得到含全反式维生素 A 乙酸酯的教学晶体。它没有完成 GT 原生原料供给和真实工业校准，不能作为药用质量结果。

## 1. 先辨认三个工段

共 20 台：偶联 8 台、乙酰化 6 台、后段 6 台。每台均有右键 UI；数量单位是 mol，当前不使用 GT 桶、管道、瓶子或 IFluidHandler。

聊天栏输入 `/occhain status` 核对版本。旧实例仍保留但不能连接版本不同的新服。不要删旧世界账本。

新建偶联线采用 `va-coupling-extent-2`，加入剩余乙基试剂竞争加成。已有 v1 线保持原模型；若使用旧批次，产量不同是模型版本和实际源数量不同，不能与下方新建基线混比。

## 2. 放置并连接，不能省掉绑定步骤

在同一片平地依次创建。三个命令都从玩家坐标南侧第三格开始，沿东向排列；更换站立位置，留出至少四格南北间距。建议二十台都安排在彼此相距几十格内，保持全部加载。

1. `/occouple place`：记录返回的 **偶联线 UUID**；它创建八台。
2. 到另一排空地执行 `/ocva place`：记录 **乙酰化线 UUID**；它创建六台。**此时不要装载乙酰化夹具。**
3. 到第三排空地执行 `/occhain place <偶联线UUID> <乙酰化线UUID>`：把尖括号及中文替换成刚得到的真实 UUID；创建六台后段设备。

两条源线必须属于自己、处于同一维度；乙酰化线必须 EMPTY。每条源线只允许绑定一个后段。错误会给出原因，不会覆盖已有方块。`/occouple status`、`/ocva status`、`/occhain status` 可找回自己的 UUID、阶段及坐标。

后段六台从西向东如下：

| 编号 | 右键标题 | 功能 |
|---|---|---|
| 0 | 工段接收 / 辅料 | 投放一次辅料夹具、接收所绑定偶联线的 C20 物流 |
| 1 | 选择性加氢釜 | 选择性部分加氢或过还原对照，二选一 |
| 2 | 催化剂过滤 / 交接 | 过滤与中间体分配；交接到绑定的乙酰化线 |
| 3 | 脱水重排釜 | 接收乙酰化分离后的中间料；执行复合净工序 |
| 4 | 结晶 / 成品分析 | 结晶分配；查看两种异构体和质量门 |
| 5 | 母液 / 废料 / 催化剂 | 查看废溶剂、水、残余、过还原物、催化剂和母液 |

只有放置者可打开控制面；辅料夹具额外要求管理员权限。后段按钮还要求绑定的全部设备齐全、所在区块已加载。

## 3. 先跑完新建偶联线

操作顺序与 [偶联手册](coupling-manual.html) 相同，但新建模型的基线数字已经变化。使用“痕量水夹具”，执行：

`第0台装料 → 第0台干燥 → 第0台入釜 → 第1台双活化 → 第2台收乙烷 → 第3台合并进料 → 第4台偶联 → 第5台酸性后处理 → 第2台收剩余乙烷 → 第5台教学分离`

新模型在偶联时先用 `min(余量EtMgBr,C14) × 0.25` 做教学竞争分配，再计算目标偶联。干燥基线结果：

| 检查位置 | 期望数量 / mol |
|---|---|
| 第 6 台目标 C20 炔二醇 | **0.88445** |
| 第 6 台乙醚 / 水 | 0.1 / 0.05 |
| 第 7 台 C16 竞争加成醇 | **0.05** |
| 第 2 台累计乙烷 | **2.15** |
| 本批目标偶联进度 | 0.9025 |

竞争试剂的乙基进入 C16 副产物，因此最终乙烷比旧模型少 0.05 mol；元素仍守恒。25% 是顺序分配教学参数，不是经过测量的竞争动力学。

## 4. 后段装辅料与接收 C20

右键后段第 0 台，先点击 **装载辅料夹具**，等待提交确认，再点击 **接收 C20 物流**。

辅料夹具只补以下资源，**不会生成 C20、hydroxenin 或乙酸酯中间体**：

| 存放处 | 资源 / mol |
|---|---|
| 后段第 1 台气体 | H₂ 1.1 |
| 后段第 1 台固体 | Pd 0.001、CaCO₃ 0.1、Pb 0.001 |
| 后段第 1 台液流 | 喹啉 0.01 |
| 后段第 0 台液流 | 乙酸酐 1.3、吡啶 0.8、对二甲苯 10 |

催化剂配方和初始活性 1 是教学夹具。没有声称这是工业 Lindlar 制备比例。

接收后偶联第 6 台液流清空，后段第 1 台增加对应 C20、乙醚、水；两端库存与交接凭证在同一次账本提交中变化。关闭 GUI 不等于取消已经进入写盘阶段的事务，重新打开按已确认库存继续。

## 5. 部分加氢、过滤与交接乙酰化

1. 后段第 1 台点击 **选择性部分加氢**。不要同时尝试“过还原对照”；两种操作只能选一种。本批 95% 炔二醇进入加氢，其中 2% 的生成 H 继续过还原。
2. 后段第 2 台点击 **过滤并分配中间料**。98% 的 H 分配至第 2 台，其余液流与固体进入第 5 台；余 H₂ 保留在第 1 台。该步骤是“过滤 + 理想中间体分配”的合并教学工序，不是真实过滤器能独自完成的纯化。
3. 同一台点击 **交接乙酰化进料**。H 与第 0 台辅料一同转入绑定乙酰化线的第 0 台，目标阶段变为 LOADED。

干燥基线选择性模式应有：

| 数量 | mol |
|---|---|
| H₂ 消耗 / 剩余 | 0.85703205 / 0.24296795 |
| 初次加氢进度 | 0.8402275 |
| 过还原物 | 0.01680455 |
| 加氢后 H | 0.82342295 |
| 交接乙酰化的 H | 0.806954491 |
| 废流中 H | 0.016468459 |
| 未反应 C20 炔二醇 | 0.0442225 |

催化剂材料全部留在第 5 台固体库存；有效活性记录变为 0.9。当前没有连续多批或自动再生。

## 6. 在原有乙酰化线运行一次

到绑定的乙酰化六机线操作，**不要点击装载教学原料**：

1. 第 0 台点击“计量入釜”。默认 303 K，按本基线保持此温度。
2. 第 1 台点击“自动本批”。默认每 20 tick 推进 300 模型秒；正常 20 TPS 下约 12–15 秒，加上账本排队时间。看进度达到 3600 模型秒和阶段 REACTED 后再继续。
3. 第 1 台“出釜并过滤”。
4. 第 3 台“分离中间料”。
5. 停在 SEPARATED；**不要包装**，也无需领取纸质引用。

若过早包装，目标物流已进入样品账，后段将明确拒绝接收；本版没有逆向拆包入口。新实验应新建一套空线。

## 7. 回后段做净重排与结晶分配

1. 后段第 3 台点击 **接收乙酰化中间料**。接收的是完整分析机液流，包含残余和微量溶剂；乙酰化第 4 台清空。
2. 后段第 3 台点击 **脱水重排净工序**。本教学设定为 90% 单乙酸酯转化，按 80:20 分配全反式与指定单 Z 结构，并保留生成水、未转化物和其他组分。
3. 后段第 4 台点击 **结晶分配 / 质检**。全反式回收 90%，单 Z 夹带 1%，其余进入第 5 台母液。

新建干燥基线、选择性加氢、303 K 乙酰化最终约为：

| 第 4 台固体 | 数量 / mol |
|---|---|
| 全反式维生素 A 乙酸酯 | **0.2609166427** |
| 指定单 Z 比较体 | **0.00072476845** |
| 晶体池中全反式摩尔分数 | **99.723%** |

第 4 台“全线 / 诊断”应显示通过 ≥99% 教学质量门。晶体仍是两种组分的混合物；这一质量门没有覆盖现实全部杂质、残溶或药典要求。产品留在设备账本，无瓶装或 GT 物品导出。

## 8. 对照实验与 UI 验收

另建完整一套线，在第 1 台选择“过还原对照”：初次加氢生成量的 20% 继续还原，最终全反式晶体约 **0.1643596509 mol**。若偶联用 0.3 mol 湿料并跳过干燥、后段仍选择性加氢，约 **0.2311211284 mol**。这展示教学参数如何影响物料，不是工业最优条件。

后段每台 UI 都有本机库存、三组曲线、全线诊断。确认气体/固体没有被误标为液体；曲线横轴是后段工序；查看原乙酰化时间曲线时应去乙酰化设备。

由你人工验收客户端：不同 GUI 缩放下按钮和文本是否重叠；20 台右键是否可用；禁用原因是否清楚；三次交接的数量是否对应。自动验收没有操控 Minecraft 桌面窗口。

## 9. 重启、丢失绑定与版本升级

新建竞争模型或后段线会将账本升级至 v2.3，旧 v1 偶联和乙酰化数据继续加载。不能只替换旧 JAR 降级；需要匹配升级前完整世界备份。

重进服后用三个 status 命令找原线，核对阶段、产品、H₂ 余量、催化剂和母液。需要恢复丢失空壳时分别用 `/occouple repair <UUID>`、`/ocva repair <UUID>`、`/occhain repair <UUID>`；只在原坐标空位恢复绑定，不复制物料或覆盖其他方块。

`/occhain report` 导出全账本和三次交接；`/occhain qa` 为管理员在保留区执行完整服务端串联验收。每世界上限为 8 条偶联线、16 条乙酰化线、4 条后段线；QA 占其中一套。

## 10. 本轮通过标准与仍开放的工作

通过要求：新模型副产物和数量匹配；三次交接不复制；已有乙酰化反应真实执行；最终两种晶体与母液分别存在；重启后保存；错误窗口/玩家/阶段不能提交。

未完成：GT 原生原料供给、容器导入/导出、真实动力学与物性、连续催化剂再生、结晶相平衡、E03 逐步微观机理、独立化学审核。后续将优先推进上游原料支线与这些门槛，不把本次开发夹具闭环描述成原生工业线已完成。
