原料获取与 OC 配方

全部外购原辅料都有 OC 新增的 GT 设备配方。中间体由主线生成，β-紫罗兰酮无需测试发料。

配方由谁添加，原料从哪里来？

本页 37 条配方全部由 OC 添加到 GT 大型化学反应釜：20 条物料封装、13 条聚合合成、4 条游戏耗材。原生输入物料 ≠ 原生合成配方。输入注册和配方匹配已在此整合包核验；原生上游的制取路径以当前 NEI 为准。

目前保留全部配方。未来独立支线先与原配方并存，用版本化配置选择成本和解锁；已有工艺包和库存身份保持可读取。

先做包，再放入中央双箱

在 NEI 搜索原料包或下面的物种 ID。液体和气体从 GT 流体输入仓进入大型化学反应釜，粉末与已有原料包从输入总线进入，输出总线接物品管或漏斗到 OC 中央双箱；流体副产物接独立输出仓与储罐。电路不消耗。含多步合成的配方是游戏聚合工艺，不能将一条 NEI 配方读作单个基元反应。

把聚合配方逐条展开为制备支线

下面是工程候选路线，用于确定设备、物料和研究范围；不是已建成的产线或实验操作规程。优先顺序：甲醇钠 → 异丙醇 / 铝醇盐 → 配体 / 钼催化剂，其余按主线消耗与回收价值排序。

碱与醇盐支线

金属钠与氨 / 甲醇分别反应 → 分开收集氢气 → 溶剂与固体分离 → 密闭干燥供料；两种试剂不能共用含水储罐。

先拆甲醇钠，服务 C6 与配体制备；NaNH₂ 独立处理氨回收与无水边界。

sodium-amide · sodium-methoxide

异丙醇与铝醇盐

丙酮加氢 → 气液分离、氢气循环 → 醇 / 酮分离 → 干燥 → 铝醇盐反应 → 氢气接收、溶剂回收；金属活化与催化剂应单列。

与现有 MPV 支线衔接，先明确水分门槛、醇酮循环和不可回收尾流。

isopropanol · aluminium-isopropoxide

环状碳酸酯支线

环氧乙烷与 CO₂ 催化环加成 → 气体回收 → 催化剂分离 → 碳酸乙烯酯净化；乙二醇等含水副产物流单独接收。

为 U03 建独立供料单元，再比较原料消耗与催化剂寿命。

ethylene-carbonate

溴乙烷与格氏试剂

HBr 供应 → 乙醇取代 → 酸水分离 → 溴乙烷精制、干燥 → 镁插入的无水醚溶液 → 密闭转移；含镁残余局部淬灭，再进盐水处理。

醚是溶剂。当前配方的进出等量醚为游戏载体规则，不证明现场回收率为 100%。

ethyl-bromide · ethylmagnesium-bromide

β-二酮配体与钼催化剂

酮 / 酯缩合 → 酸化 → 盐水分离 → 乙酰丙酮净化 → 经确认的 Mo(VI) 前驱体配位 → 固液分离与母液回收。

当前金属钼 + 氧 + 配体是聚合游戏配方；独立工厂必须补出氧化态转换与前驱体。

acetylacetone · molybdenyl-acetylacetonate

含氮杂环支线

吡啶：醛与氨的催化缩合、气体循环、杂环混合物分馏。喹啉：Skraup 路线候选，独立计入酸催化、氧化剂、反应后中和与含氮废水。

不能由净式推定单一异构体或纯品；先做混合物身份和分离验收。

pyridine · quinoline

取代芳香酸支线

异丁醛 → 异丁醇 → 异丁烯；甲苯烷基化 → 邻 / 对位分离 → 侧链氧化 → 酸产品结晶、母液接收。

当前结构身份明确为 4-叔丁基苯甲酸。独立制备必须实现对位分离与质量门，不能把烷基化混合物直接标为对位纯品。

tert-butylbenzoic-acid

有机磷试剂与回收

氯苯 → 苯基有机镁试剂 → PCl₃ 取代、盐分离 → 三苯基膦 → 氧化成氧化物；回收须区分膦与膦氧化物身份。

把镁盐、醚溶剂、含磷残余分别接收；不能把膦氧化物直接当成同活性的膦回用。

triphenylphosphine-oxide

每条支线的交付门槛

  1. 核对原生供料身份、净反应与催化剂角色；聚合计量不得冒充实际工业操作。
  2. 拆出反应、分离、回用、局部处理和中央处置；每股物料都绑定容器与容量。
  3. 建立质量门、能耗和停机规则，完成缺料、满仓、两批运行和重启测试，再替代聚合配方。
