## 1. 依据与证据等级

EP2225193B1 的背景描述支持 C6-Z 与 C14 醛经 Grignard 偶联、部分加氢、末端乙酰化、脱水/重排和结晶的路线顺序。其主要主题是 C6 光异构化，不能为全部偶联动力学、收率、干燥要求或盐相行为背书。

本版逐步箭推属于原创教学展开；95% 限量反应物进度、98% 目标物分配、1% 溶剂/水夹带、0.5 mol 水域和吸水容量均为游戏参数。真实速率、浓度、压力、热量、产率和相平衡未经校准。

## 2. 两个表示层

过程库存采用中性有效组分：C6H7MgBrO、C6H6Mg2Br2O、C20H28Mg2Br2O2、MgBrOH。这些公式用于元素当量和来源追踪，不声明溶液中存在相应唯一分子。

机理图采用极限离子表示：有机负离子、Mg²⁺、Br⁻。醇盐和炔负离子的完整碳骨架、显式氢、反离子均保留。它不是自由碳负离子真实活度、Schlenk 平衡或聚集态模型。镁配位和溶剂化目前省略并显式标注。

## 3. 需要审核的净计量

| 工序 | 净式 | 需核对 |
|---|---|---|
| 水失活 | EtMgBr + H₂O → C₂H₆ + MgBrOH | 单镁羟溴有效组分是否合适；与原规格双分子总式等价的当量解释 |
| 羟基活化 | C₆H₈O + EtMgBr → C₆H₇MgBrO + C₂H₆ | OH 优先、限量条件的教学域 |
| 端炔活化 | C₆H₇MgBrO + EtMgBr → C₆H₆Mg₂Br₂O + C₂H₆ | 炔键不降阶、C–H 脱质子、MgBr 计账 |
| 偶联 | C₆H₆Mg₂Br₂O + C₁₄H₂₂O → C₂₀H₂₈Mg₂Br₂O₂ | 连结位点、氧与碳映射、C6 继承构型 |
| 目标后处理 | C₂₀H₂₈Mg₂Br₂O₂ + H₂SO₄ → C₂₀H₃₀O₂ + MgBr₂ + MgSO₄ | 两处氧质子化；新醇立体中心未指定 |
| 剩余二镁体 | C6-di + H₂SO₄ → C6 + MgBr₂ + MgSO₄ | 未反应底物回归，并非都转产品 |
| 单镁体 | C6-mono + ½H₂SO₄ → C6 + ½MgBr₂ + ½MgSO₄ | 分数系数为 mol 当量 |
| 剩余试剂 | EtMgBr + ½H₂SO₄ → C₂H₆ + ½MgBr₂ + ½MgSO₄ | 后处理新增气体 |
| 失活体 | MgBrOH + ½H₂SO₄ → H₂O + ½MgBr₂ + ½MgSO₄ | 水返回流动库存 |

所有计量以 BigDecimal 做元素守恒。盐视为有效溶解组分；没有声称沉淀。前一轮规划中的“Mg/Br/Cl 废物流”在本工段应修正为 **Mg/Br/S**；Cl 属于上游氯乙酸/Darzens 等来源，不应凭空出现在本段。

3. C6 继承构型、C14 醛异构体和新醇中心的标签是否准确？后续部分加氢与脱水/重排如何避免过早声称全反式？

5. 使用示意构象讲电子对是否存在误导的空间接近、箭头方向或遗漏？哪些帧应补溶剂化或配位限定？
